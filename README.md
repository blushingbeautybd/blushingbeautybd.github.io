# Blushing Beauty

Online shop website for Blushing Beauty (bras, panties, lingerie sets, nightwear, beauty care).
Orders are sent on WhatsApp. Products, prices, banners and reviews are managed from `admin.html`.

## Updating the shop

Open https://blushingbeautybd.github.io/admin.html, log in with a fine-grained GitHub token
(repository `blushingbeautybd.github.io`, permission **Contents: Read and write**), make changes and press **পাবলিশ করুন**.
The admin writes `assets/data/site.json`, `assets/js/config.js` and uploaded photos (`images/u/`) in one commit;
GitHub Pages redeploys in 1–2 minutes.
