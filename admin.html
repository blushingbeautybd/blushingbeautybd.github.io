অ্যাডমিন লগইন

শুধু দোকানের মালিক লগইন করতে পারবেন।

ডেটা লোড হচ্ছে…

লোকাল মোড চালু আছে। পরিবর্তনগুলো শুধু এই ব্রাউজারে সেভ থাকে। সব কাস্টমারকে দেখাতে নিচের বার থেকে config.js ডাউনলোড করে হোস্টিং এ assets/js/config.js ফাইলটা বদলে দিন। সরাসরি লাইভ সেভ চাইলে "ব্যাকআপ ও সেটআপ" ট্যাবে Supabase সেটআপ দেখুন।

দাম সরাসরি ঘরে লিখে দিন। ঘর খালি রাখলে সাইটে "দাম জানুন" দেখাবে। সব শেষে নিচের বার থেকে পাবলিশ করুন।

    ব্যাকআপ

    সব পণ্য আর সেটিংস একটা ফাইলে রেখে দিন। পরে এখান থেকেই ফিরিয়ে আনা যাবে।

    config.js ফাইল

    এখনকার সব পণ্য আর সেটিংস দিয়ে নতুন config.js তৈরি হবে। হোস্টিং এ assets/js/config.js এর জায়গায় এটা রাখলে সাইটে দেখাবে। ক্লাউড মোডেও এটা রাখা ভালো, ক্লাউড বন্ধ থাকলে সাইট এটা দেখায়।

    লাইভ সেভ (Supabase) সেটআপ

    1. supabase.com এ ফ্রি অ্যাকাউন্ট খুলে একটা নতুন প্রজেক্ট বানান।
    2. SQL Editor খুলে supabase-setup.sql ফাইলের সব লেখা পেস্ট করে Run চাপুন।
    3. Authentication থেকে Users এ গিয়ে Add user দিয়ে নিজের ইমেইল আর পাসওয়ার্ড দিন। তারপর Sign In / Providers এ নতুন সাইন আপ বন্ধ করে দিন।
    4. Project Settings থেকে API তে গিয়ে Project URL আর anon public key কপি করে assets/js/cloud-config.js ফাইলে বসান।
    5. সাইট আবার আপলোড করে এই পেজে লগইন করুন। এরপর প্রতিটা পাবলিশ সাথে সাথে সবার কাছে লাইভ হবে।
